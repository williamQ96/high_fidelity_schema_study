## Purpose

This ledger binds each manuscript-level claim to its authoritative evidence,
epistemic class, permitted wording, and invalid overstatement. It is a
publication-control artifact: an apparently plausible sentence is not eligible
for the manuscript unless the cited evidence supports the same population,
estimand, stage, and level of certainty.

Claim classes are:

- **artifact fact**: directly recomputable from a content-addressed artifact;
- **engineering validation**: code or synthetic tests establish a contract or
  failure mode, not scientific performance;
- **descriptive diagnostic**: observed on development or qualification data
  without confirmatory interpretation;
- **registered future estimand**: precisely defined but not yet estimated;
- **literature-grounded framing**: prior work supports the rationale, not a
  project result;
- **unresolved**: evidence is absent or a required gate has not passed.

## Release rules

Before any manuscript release:

1. every quantitative sentence must name a ledger ID or an evidence artifact;
2. every `registered future estimand` must remain in future tense until a valid
   inference artifact exists;
3. every unresolved claim must remain a placeholder or explicit limitation;
4. public materials must not expose sealed test identities;
5. a changed artifact hash invalidates the corresponding ledger evidence until
   the ledger is refreshed;
6. a collaborator's review cannot be relabelled as independent validation;
7. test passage, successful compilation, or a completed template cannot upgrade
   a scientific claim.

## Required update after blind execution

This ledger must receive a new version rather than being edited in place. The
post-test version must add:

- test-release authorization and preregistration receipt;
- test case/run/inference artifact hashes;
- realized missingness and comparability counts;
- primary effect estimates, intervals, raw and Holm-adjusted p-values;
- power/assurance reconciliation;
- all deviations;
- an explicit decision for every previously unresolved scientific claim.
